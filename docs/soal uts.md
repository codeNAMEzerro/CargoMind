Dalam UTS ini, setiap tim diminta menyusun sebuah dokumen terpadu bernama
Software Project Blueprint (SPB). Dokumen ini merepresentasikan kesiapan tim
dalam membangun sistem, mulai dari analisis kebutuhan, perancangan sistem,
hingga jejak kolaborasi tim.
Penilaian dilakukan menggunakan
[sub.cpmk.ST165.CPMK16.1, sub.cpmk.ST165.CPMK16.1. Max: 100 poin]:
* Performance Assessment (proses & kontribusi tim)
* Product Assessment (kualitas dokumen)
Dokumen harus disusun secara sistematis dan minimal memuat bagian berikut:
1. Pendahuluan
a. Latar belakang
b. Tujuan pengembangan sistem
c. Deskripsi singkat sistem
2. Kebutuhan Sistem (System Requirements)
a. Identifikasi stakeholder & user
b. Functional Requirements (berbasis Use Case, bukan Use Case
Digram)
c. Use Case Diagram
d. Deskripsi Use Case (minimal use case utama)
e. Non-Functional Requirements
3. Desain Sistem (System Design)
a. Arsitektur Sistem (misal: client-server, jelaskan detail asristekturnya,
bisa menggunakan digram jika diperlukan)
b. Activity Diagram (Activity Diagram dibuat untuk merepresentasikan
alur proses dari Use Case utama. Tidak semua Use Case harus
dibuatkan Activity Diagram, pilih proses yang paling signifikan atau
kompleks).
c. Database Design (ERD)
d. High Fidelity UI Design (Anda bisa menggunakan Figma / tools lain)
4. Repository Tim (Performance Evidence)
a. Link Git Repository
b. Screenshot repository
c. Struktur branch (jelaskan branch yang digunakan)
d. Commit Activity:
i. Screenshot / ringkasan kontribusi anggota
ii. Penjelasan singkat aktivitas tim
Ketentuan format dokumen yang dikumpulkan dalam tugas ini adalah sebagai berikut:
1. Format dokumen: PDF (Max: 2 MB)
2. Template: Bebas (profesional & rapi)
3. Halaman Cover (Wajib):
a. Nama Tim
b. Logo Tim
c. Nama Proyek
d. Nama anggota
e. NIM
f. Role masing-masing anggota
Ketentuan Pengumpulan
1. Tugas dikerjakan secara berkelompok (tim)
2. Setiap anggota tim WAJIB mengunggah (upload) dokumen yang sama ke
dashboard masing-masing
3. Pastikan file yang diunggah adalah versi final dan konsisten antar anggota
